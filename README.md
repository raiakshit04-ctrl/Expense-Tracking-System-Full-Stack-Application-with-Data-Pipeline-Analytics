# 💰 Expense Tracking System – Full-Stack Data Application

## 📌 Overview
A full-stack expense tracking system that allows users to manage, analyze, and visualize financial transactions in real time. Designed with a focus on data processing, automation, and scalability.

---

## 🚀 Features
- User authentication (JWT-based)
- CRUD operations for financial transactions
- Real-time data storage and retrieval
- Automated reporting and analytics
- Anomaly detection for unusual spending patterns

---

## 🏗 Architecture
User → React Frontend → Django REST API → MySQL Database

---

## 🛠 Tech Stack
- Backend: Django, Django REST Framework
- Frontend: React.js
- Database: MySQL
- Languages: Python, JavaScript, SQL

---

## 📊 Key Achievements
- Managed and processed 5,000+ transaction records  
- Reduced manual expense tracking effort by 80%  
- Improved data accuracy by 35% using anomaly detection  

---

## 📈 What This Project Demonstrates
- Backend API design and development  
- Database design and SQL optimization  
- Data processing and workflow automation  
- Full-stack system integration
